# いい街こまつプレミアム 取扱店検索

小松市のプレミアム付商品券取扱店を検索できる静的Webアプリです。  
店舗名、カテゴリ、施設名、住所から検索し、一覧表示できます。

## 概要

このシステムは、以下のようなユースケースを想定しています。

- プレミアム付商品券の取扱店を簡単に検索したい
- 施設ごと、業種ごとに絞り込みたい
- スマートフォンでも使いやすい検索画面を提供したい
- 簡単に公開・更新できる静的サイトとして運用したい

## 主な機能

- 店舗名・住所によるキーワード検索
- カテゴリによる絞り込み
- 施設名（例: アル・プラザ小松、イオン小松店等）での絞り込み
- 取扱店一覧の表示
- レスポンシブ対応
- データを `stores.json` で管理し、更新が簡単

## 技術構成

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- JSONによるデータ管理
- 静的サイト構成（サーバー不要）

## 実行方法

ローカル環境で表示する場合は、任意の静的サーバーを立ち上げてアクセスしてください。

### 例: Pythonでローカルサーバーを起動

```bash
cd komatsu-premium-search
python -m http.server 8000
```

その後、ブラウザで次のURLへアクセスします。

```text
http://localhost:8000/
```

## データ形式

`stores.json` は次の形式の配列データです。

```json
[
  {
    "facility_type": "複合商業施設",
    "facility_name": "アル・プラザ小松",
    "category": "飲食",
    "shop_name": "カフェテラス ミツバ",
    "address": "園町ハ23番地1"
  }
]
```

- `facility_type`: 施設の種別
- `facility_name`: 施設名
- `category`: 業種・カテゴリ
- `shop_name`: 店舗名
- `address`: 住所

## カスタマイズポイント

### タイトルや見た目の調整
`index.html` の `<style>` セクションで以下を調整できます。

- ヘッダー色
- フォント
- ボタンやテーブルの見た目
- レスポンシブ調整

### データ更新
店舗情報を追加・修正する場合は、`stores.json` の項目を編集してください。

## 制約事項

- 現在は静的サイトのため、バックエンド処理はありません。
- データ更新はファイル編集で行います。
- 認証・ログイン・管理画面機能は含まれていません。
